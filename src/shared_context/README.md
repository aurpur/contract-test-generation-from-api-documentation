# Shared Context Module

## Overview

The **Shared Context** module provides the infrastructure for agents (Inductor, Oracle, Contractor, Runner) to communicate, share state, and persist data during the test generation workflow.

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│                    Context Manager                       │
│  High-level API for agents to interact with context     │
└─────────────────┬───────────────────────────────────────┘
                  │
┌─────────────────▼───────────────────────────────────────┐
│                  Storage Backend                         │
│  ┌──────────────┐              ┌──────────────┐         │
│  │  PostgreSQL  │              │    Redis     │         │
│  │  (Durable)   │              │   (Cache)    │         │
│  └──────────────┘              └──────────────┘         │
└─────────────────────────────────────────────────────────┘
```

## Components

### 1. Models (`models.py`)

Pydantic models defining the data structures:

- **WorkflowSession**: Tracks the entire test generation process
- **EndpointContext**: API endpoint information extracted by Inductor
- **Oracle**: Validation rules derived by Oracle agent
- **GeneratedTest**: Test code generated by Contractor agent
- **TestExecutionResult**: Results from Runner agent
- **AgentMessage**: Inter-agent communication
- **Metrics Models**: For research questions (RQ1-RQ5)

### 2. Context Manager (`context_manager.py`)

High-level API for agents to:
- Create and manage workflow sessions
- Store and retrieve agent outputs
- Send messages between agents
- Track metrics and analytics
- Manage feedback loop iterations

### 3. Storage Backend (`storage.py`)

Persistence layer with:
- **PostgreSQL**: Durable storage for all data
- **Redis**: Fast cache for frequently accessed data
- **SQLAlchemy**: ORM for database operations
- **Async support**: Non-blocking I/O operations

## Usage

### Basic Example

```python
from shared_context import ContextManager, create_storage_backend, AgentType

# Initialize
storage = await create_storage_backend()
context_manager = ContextManager(storage)

# Create a session
session = await context_manager.create_session(
    collection_name="My API",
    collection_path="/path/to/collection.json",
    llm_models={
        AgentType.INDUCTOR: "mistral",
        AgentType.ORACLE: "llama3.1",
    }
)

# Add endpoint (by Inductor)
from shared_context import EndpointContext, HTTPMethod

endpoint = EndpointContext(
    name="Get Users",
    method=HTTPMethod.GET,
    url="/api/users",
    expected_status=200,
)
await context_manager.add_endpoint(session.id, endpoint)

# Add oracle (by Oracle)
from shared_context import Oracle

oracle = Oracle(
    endpoint_id=endpoint.id,
    status_code=200,
    required_headers=["Content-Type"],
    confidence_score=0.95,
)
await context_manager.add_oracle(session.id, oracle)

# Add test (by Contractor)
from shared_context import GeneratedTest

test = GeneratedTest(
    endpoint_id=endpoint.id,
    oracle_id=oracle.id,
    test_class_name="GetUsersTest",
    test_method_name="testGetUsersReturns200",
    test_code="@Test\npublic void test...",
)
await context_manager.add_test(session.id, test)

# Add execution result (by Runner)
from shared_context import TestExecutionResult

result = TestExecutionResult(
    test_id=test.id,
    passed=True,
    execution_time_ms=123.45,
    actual_status_code=200,
)
await context_manager.add_execution_result(session.id, result)

# Cleanup
await context_manager.close()
```

### Inter-Agent Communication

```python
# Inductor sends message to Oracle
message = await context_manager.send_message(
    session_id=session.id,
    from_agent=AgentType.INDUCTOR,
    to_agent=AgentType.ORACLE,
    message_type="context_ready",
    payload={"endpoints": 10},
    priority=1,
)

# Oracle retrieves messages
messages = await context_manager.get_messages(
    session.id,
    to_agent=AgentType.ORACLE,
)
```

### Feedback Loop Management

```python
# Check if should retry
if await context_manager.should_retry(session.id):
    # Increment iteration
    iteration = await context_manager.increment_iteration(session.id)
    print(f"Retry iteration {iteration}")
```

### Metrics Tracking

```python
from shared_context import QualityMetrics, InconsistencyReport

# Add quality metrics (RQ3)
metrics = QualityMetrics(
    session_id=session.id,
    assertion_count=10,
    valid_assertions=9,
    quality_score=0.85,
)
await context_manager.add_quality_metrics(metrics)

# Add inconsistency report (RQ2)
report = InconsistencyReport(
    session_id=session.id,
    oracle_id=oracle.id,
    test_id=test.id,
    inconsistency_type="status_code_mismatch",
    severity="critical",
    description="Oracle expects 200 but test checks 201",
    detected_by="automated_analyzer",
)
await context_manager.add_inconsistency_report(report)
```

## Configuration

Configure database connections in `config/llm_config.yaml`:

```yaml
database:
  postgres_url: "postgresql+asyncpg://user:pass@localhost:5432/contract_tests"

redis:
  host: "localhost"
  port: 6379
  db: 0
  cache_ttl: 3600  # Cache TTL in seconds
```

## Data Flow

```
┌──────────────┐
│  Inductor    │ ──► Extracts endpoints
└──────┬───────┘
       │
       ▼
┌──────────────────┐
│ Context Manager  │ ──► Stores EndpointContext
└──────┬───────────┘
       │
       ▼
┌──────────────┐
│   Oracle     │ ──► Derives validation rules
└──────┬───────┘
       │
       ▼
┌──────────────────┐
│ Context Manager  │ ──► Stores Oracle
└──────┬───────────┘
       │
       ▼
┌──────────────┐
│  Contractor  │ ──► Generates test code
└──────┬───────┘
       │
       ▼
┌──────────────────┐
│ Context Manager  │ ──► Stores GeneratedTest
└──────┬───────────┘
       │
       ▼
┌──────────────┐
│   Runner     │ ──► Executes tests
└──────┬───────┘
       │
       ▼
┌──────────────────┐
│ Context Manager  │ ──► Stores TestExecutionResult
└──────────────────┘
```

## Features

### 1. Persistence
- All data stored in PostgreSQL for durability
- Survives system crashes and restarts
- Full audit trail of all operations

### 2. Performance
- Redis caching for fast access
- Configurable TTL (default: 1 hour)
- Reduces database load

### 3. Async Operations
- Non-blocking I/O
- Supports concurrent agent operations
- Scales to high throughput

### 4. Research Support
- Metrics for all RQs (RQ1-RQ5)
- Inconsistency detection (RQ2)
- Quality analysis (RQ3)
- LLM performance tracking (RQ4)
- Completeness impact (RQ5)

### 5. Feedback Loop
- Iteration tracking
- Automatic retry management
- Convergence detection

## Best Practices

1. **Always use context manager** for high-level operations
2. **Close connections** when done (`await context_manager.close()`)
3. **Use async/await** for all operations
4. **Check session status** before operations
5. **Set appropriate cache TTL** based on workload
6. **Monitor Redis memory** usage
7. **Back up PostgreSQL** regularly
