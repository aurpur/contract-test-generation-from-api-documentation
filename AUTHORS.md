## Research Context

This project is part of a research initiative investigating the use of AI agents and Large Language Models (LLMs) for automated test generation from API documentation.

### Research Questions Addressed:
- RQ1: Oracle Generation from API Documentation
- RQ2: Gap Detection and Reduction in Multi-Agent Systems
- RQ3: Test Validity (Correctness, Readability, Maintainability)
- RQ4: LLM Model Performance Comparison
- RQ5: Incomplete Documentation Handling
