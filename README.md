# Contract Test Generation from API Documentation

## Description

Ce projet automatise la génération de tests de contrat à partir de documentation d'API. Il permet de créer automatiquement des tests qui vérifient que l'implémentation d'une API respecte sa spécification, assurant ainsi la cohérence entre la documentation et le comportement réel de l'API.

## Fonctionnalités

- Génération automatique de tests de contrat
- Support de multiples formats de documentation API
- Validation de la conformité entre spécification et implémentation
